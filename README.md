# healthcare-dashboard
 This dashboard helps analyze patient data and hospital performance to support better healthcare decisions.
Key Insights Covered:
 • Patient count by age, gender, and department
 • Admission and discharge trends
 • Department-wise workload analysis
 • Length of stay and treatment patterns
 • Time-based patient flow insights
Tools & Skills Applied:
 Power BI • Data Modeling • DAX • Healthcare Analytics • Data Visualization
This project focused on transforming healthcare data into meaningful insights for operational efficiency.
